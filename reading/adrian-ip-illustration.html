視覺印記：每一個 IP 都應該有一套屬於自己的插圖

過去一段時間，我一直在寫教學長文。

內容越寫越完整，步驟越拆越細，但我始終覺得少了點什麼。

文字很多，資訊也足夠，可是讀者打開文章以後，依然需要花很長時間理解。一整個螢幕的文字連續往下鋪，就算內容本身有價值，也很容易帶來閱讀壓力。

尤其是教學、工作流程和方法論文章，很多內容其實並不適合只靠文字表達。

一個流程怎麼運作，一個工具怎樣處理資訊，一個人在某種處境裡遇到了什麼問題，這些東西本來是可以直接「看見」的。

所以我開始嘗試留下一點視覺印記——長文插圖。

我測試了很多種人物風格、場景結構、畫面比例和資訊密度，最後才逐漸確定了現在這套方案：

先固定個人 IP，再產生 IP 小劇場

第一步：用自己的照片，產生一張穩定的 IP 角色設定圖

角色設定圖提示詞

請根據我上傳的人物照片，產生一張「復古扁平立體角色設定圖」。

角色名稱：{{填寫名字或暱稱}}

把照片中的真人轉化為可以長期重複使用的個人 IP 角色，做成一張直式的角色設定板。整體採用復古扁平立體插畫風：以扁平為主，輕微立體，低細節，低飽和，柔和陰影，霧面質感，輕微復古顆粒，淺米白或暖白背景，版面乾淨，留白充足，像專業角色設計手冊的一頁。

人物必須以我上傳的照片為唯一參考，保留最有辨識度的特徵，包括臉型、五官比例、眼神氣質、眉毛、鼻子、嘴唇、髮型、髮際線、年齡感、膚色、體型輪廓和整體氣質。表現方式是扁平化的角色轉譯，不要寫實，不要二次元，不要潮玩公仔，不要過度可愛，不要大頭娃娃。

服裝參考原照片，可以適度簡化成更適合長期使用的固定角色造型。要求簡潔、日常、有辨識度，減少複雜的皺褶和真實布料紋理，不加無關的品牌標誌和多餘配飾。

固定版式：
1. 頂部置中寫「{{填寫名字或暱稱}}」
2. 標題下方小字寫「角色設定」
3. 中上部放一個最大的主角色全身像，站在簡潔的圓形底座上，姿態自然放鬆
4. 底部橫向排列四個小角色視圖，依序為：
正面 / FRONT
左側 / LEFT SIDE
背面 / BACK
右側 / RIGHT SIDE

四視圖必須保持完全一致：同一個髮型、臉型、衣服、鞋子、配件、顏色和身體比例。

不要左側配件區，不要配色區，不要人物介紹，不要個性說明，不要長段文字，不要多餘英文，不要亂碼，不要複雜場景。

最終輸出為一張清晰、工整、可以長期重複使用的個人 IP 角色設定圖，比例為 3:4 或 4:5。

IP 小劇場提示詞

請根據我上傳的個人 IP 角色設定圖，以及下面提供的主題或文字，產生一張「復古彩色扁平 3D IP 小劇場」長文插圖。

主題或文字：
{{貼上主題、觀點或段落}}

模式：
{{流程拆解 / 核心動作 / 自動判斷}}

畫面比例固定為橫式 16:9。背景必須是純白色頁面，不使用米黃色、漸層、紋理背景或完整的空間背景。畫面用於長文內文插圖，不做封面，不放大標題。主體小劇場控制在畫布中間區域，整體約佔畫面的 55%—65%，不能過大，不能貼邊，四周必須保留明顯留白。整體像擺在白色頁面上的一組精緻桌面模型，清爽、克制、有呼吸感。

必須嚴格依照上傳的 IP 角色設定圖還原人物，完整保留臉型、五官比例、髮型、髮際線、膚色、固定服裝、鞋子、配件、整體氣質和身體比例。不得重新設計人物，不得更換服裝，不得增加設定圖中沒有的顯眼配件。允許變化的只有動作、姿態、方向、視線和輕微表情。無論人物在畫面中出現幾次，都必須保持完全一致。

先理解輸入的內容，再提煉最重要的結論。不要逐句翻譯原文，也不要把所有資訊都塞進畫面。如果內容本身是一個過程、步驟、方法、工作流程，或從輸入到輸出的完整鏈路，就使用「流程拆解模式」；如果內容本身是一個觀點、判斷、衝突、處境或現實問題，就使用「核心動作模式」。如果使用者選擇自動判斷，就先判斷哪種模式比較合適，再產生對應的畫面。

在流程拆解模式下，把內容壓縮成 3—5 個關鍵節點。每個節點只呈現一個動作和一個結果，使用風格統一的復古設備、家具、文件或其他真實物件來表達。固定的 IP 人物要參與關鍵節點，不能只是站在一旁。節點之間可以有簡潔而克制的連接關係，閱讀順序清楚，但不要做成擁擠的 PPT 流程圖。節點之間必須保留足夠的白色間距，整體保持節奏感和呼吸感。

在核心動作模式下，把整段內容壓縮成一個最值得被看見的實體現場。畫面只保留一個固定 IP 人物、一個核心物件或一組緊湊的物件、一個明確的動作和一個看得見的結果。透過人物和物件之間的物理關係表達核心觀點，不展開完整過程，不堆砌資訊，不做複雜解釋。整體必須更簡潔、更集中、更有留白，堅持 less is more。

整體視覺風格統一採用復古彩色扁平 3D 編輯插畫風格。人物與物件以扁平色塊為主，帶輕微的立體體積和輕微的等角視角。結構簡潔，低細節，邊緣清楚，使用柔和陰影、霧面材質和少量復古顆粒。顏色可以比基礎版稍微豐富一點，但仍然必須統一、克制、清爽，不花、不雜、不亂。建議從橄欖綠、芥末黃、復古藍、珊瑚紅、暖灰、奶油白、鼠尾草綠、淺卡其等顏色中選 3—5 個主色搭配，讓畫面更有層次，但不能變成高飽和的海報感。

畫面中的文字分為兩類。第一類是物件標籤，用來輔助理解物件的功能。核心動作模式最多保留 3 個標籤；流程拆解模式每個節點最多 1 個標籤。標籤控制在 2—6 個漢字，並盡量寫在文件、機器、門牌、按鈕、出口牌、便條紙或卡片上，而不是飄在空中。

第二類是畫面內部的簡短說明文字。這不是放在畫面下方的說明區，而是直接整合在畫面裡，像 plog 一樣，以紙條、便條紙、貼紙、小卡片、膠帶標籤或簡潔的註解卡形式出現。它們應該自然分布在主體旁邊或留白區域，像是在白色頁面上補充說明。依內容保留 1—2 條必要的說明就好，每條控制在 8—20 個漢字，作用是點出結論、補足語境、提高理解效率。說明文字必須短、準、輕，不要寫成長段落，不要變成大標題海報，也不要把畫面塞滿文字。

最終畫面必須滿足：固定 IP 沒有變化；畫面比例固定為橫式 16:9；背景是純白頁面；主體比例適中；四周留白明顯；顏色比原來稍微豐富一點，但整體仍然克制統一；必要的文字說明直接整合在畫面內部；核心內容可以在 3 秒內看懂；沒有無關的裝飾；沒有把畫面做成複雜的資訊圖表；沒有為了說明完整而堆積過多元素。

以下為譯者整理，非原文內容。

這篇在說什麼

長文字很容易讓人讀得累。作者的做法是：先用自己的照片做出一個固定的卡通「IP 角色」，之後每篇文章都讓這個角色出現在插圖裡，把流程或觀點「演」成一個小劇場。文章附上兩段可以直接複製的提示詞。

第一段把照片變成角色設定圖；第二段拿設定圖加上一段文字或一個主題，產生 16:9 的白底插圖，並可選擇「流程拆解」或「核心動作」兩種模式。

為什麼值得學

教學、工作流程和觀點文章，很多內容其實可以直接「看見」。用同一個角色貫穿所有插圖，讀者會越看越熟悉，你的文章也會有一致、好辨認的視覺風格。這套方法不需要會畫畫，只要會寫清楚提示詞。

你可以帶走的重點

1. 先固定角色，再換場景

角色設定圖就是「人物身分標準」。之後每張插圖都要保留臉型、髮型、服裝、配色、鞋子和配件，只改動作和姿態。先把角色定下來，插圖之間才不會像不同的人。

2. 依內容選模式：流程拆解或核心動作

內容是過程、步驟、方法或工作流程，就用「流程拆解」：壓成 3–5 個節點，每個節點一個動作、一個結果，角色要親自參與。內容是觀點、處境或現實問題，就用「核心動作」：只留一個角色、一個核心物件、一個動作和一個看得見的結果。也可以讓 AI 自動判斷。

3. 規格寫死，畫面才清爽

提示詞把版面規格寫得很具體：橫式 16:9、純白背景、主體約佔畫面 55%–65%、四周明顯留白；配色從 3–5 個復古主色裡挑；標籤 2–6 個字、寫在物件上；畫面內的說明只留 1–2 條、每條 8–20 個字；核心內容要能在 3 秒內看懂。

4. 不要把整段文字畫進去

提示詞特別要求先理解內容、提煉最重要的結論，不要逐句翻成畫面，也不要把所有資訊塞進去。像例 1，一長段關於升遷卡關的文字，最後只變成「推著成果的人」和「被鎖住的升遷位置」。

怎麼開始

  1. 準備一張清楚的自拍或半身照，貼上第一段提示詞，填入名字，產生角色設定圖；不滿意就重做，直到你願意長期使用。
  2. 挑一篇你寫過的文章，選一段流程或一個觀點，連同設定圖一起交給第二段提示詞。
  3. 同一段內容試兩種模式，比較流程拆解和核心動作哪一張更容易一眼看懂。
  4. 檢查角色有沒有走樣：臉、髮型、衣服、鞋子和配件都要和設定圖一致。

譯者提醒：原文沒有指定使用哪一個 AI 圖像模型，實際效果會依你使用的工具而不同。原文範例中的角色設定圖保留了配件區與配色區，和提示詞裡「不要配件區、配色區」的要求略有出入。
