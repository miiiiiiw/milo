先放一張表，前 6 行都是各自有各自作用的工具，都是一些很實用的新工具，用 Claude Code 把它們串起來統一調度：

一、出圖：用 MJ 出一套風格統一的參考圖

1、為什麼選擇 MJ 出圖？

其實目前可以生成圖片的大型模型已經非常多了，Codex、Seedream、Gemini，還有 MJ 都可以生成圖片，但是最近深度體驗了 MJ，我發現想要那種風格化很強的畫面，相對來說還是 MJ 最靠譜。

而且 MJ 有兩個功能，對控制風格非常有用：

  • 風格代碼：可以把自己摸索出來的風格，濃縮成一串代碼，之後每次出圖都在提示詞（prompt）裡帶上這個代碼，就可以出同一類風格的圖。
  • 情緒板：可以把一組自己很喜歡的圖放在一起做成情緒板（mood board），然後讓它照著這個感覺去出圖，這會非常穩。

有了這兩樣功能，就算是生成幾十張、幾百張圖，放在一起，風格也不容易跑偏，這對需要出大量圖，或者要保持影片質感統一還是很重要的。

2、風格代碼和情緒板，具體怎麼用？

  • 風格代碼：在提示詞（prompt）最後加上 --sref 和一串數字，就是用這個風格出圖。如果還沒有自己的代碼，有個小技巧，就是可以先寫 --sref random，這樣它就會隨機給你一個風格，然後點提交，提交以後 random 就會變成一串具體的數字，如果運氣好，出的圖片恰巧是自己喜歡的，就可以把這串數字記下來，以後一直用。或者也可以去 Explore 頁面的 Style Explorer 裡，挑別人分享出來的風格代碼。覺得風格太重或太輕，就用 --sw 調，範圍是 0 到 1000，預設 100，數字越大風格越重。
  • 情緒板：在 MJ 網站的 Moodboards 頁面點 New Moodboard，新建一個情緒板，然後把自己喜歡的圖傳上去，也可以直接從自己出過的圖裡挑。用的時候點這個情緒板的使用按鈕，提示詞（prompt）後面會自動加上 --p 和一串代碼。注意，圖挑得越統一，出來的風格就越統一；就是你得挑自己喜歡、風格又統一的放在一個情緒板裡，挑得雜，出來的圖就會比較多樣。

出圖的提示詞（prompt），可以按這個結構來寫：

[畫面裡有什麼：誰、在哪、在做什麼]，
[景別和機位]，[光線：什麼時間、光從哪邊來]，
[主要的顏色] --ar [21:9] --sref [你的風格代碼] --sw [100]

3、一個鏡頭需要配哪些圖片？

主要是這三類：

  • 每個場景一張全景，用來交代清楚這個地方長什麼樣。
  • 每個露臉的人物需要一套定妝照：正臉、全身、手。而手往往比較容易被忽略，但其實它還是很重要，很多鏡頭都會拍到手，像拿杯子這類手部動作還會拍特寫。
  • 關鍵道具，比如重要的信件、證件、武器。

這三類圖的提示詞（prompt），可以這樣寫，把括號換成你自己的就行：

場景全景：空無一人的[地點]，[時間和天氣]，全景，[平視 / 高處斜俯]，[門、窗、路]的位置看得清清楚楚 --ar 21:9 --sref [風格代碼]

定妝照·正臉：[年齡、性別、髮型、臉型特點]，正面近景，看著鏡頭，表情平靜，純淺灰背景 --ar 3:4 --sref [風格代碼]

定妝照·全身：[同一個人]全身正面站立，穿[衣服和鞋]，純淺灰背景 --ar 2:3 --sref [風格代碼]

定妝照·手：[同一個人]的雙手特寫，[手的特點：指節粗、有疤、戴戒指]，自然放在[桌面]上，純淺灰背景 --ar 3:2 --sref [風格代碼]

關鍵道具：[道具]放在純淺灰背景上，正面，光線均勻，[材質、新舊] --ar 1:1 --sref [風格代碼]

定妝照和道具盡量都用純色背景，後面當參考圖的時候，如果背景裡有雜東西就會被帶進影片裡，所以盡量用純色背景。

同一個人的幾張定妝照，可以先出一張滿意的正臉，後面全身和手這兩張都把它帶上當參考圖，長相更容易對得上、保持一致。

這些圖片出完以後，就讓 Claude 或 Codex 寫個腳本統一裁成同一個畫幅（16:9／21:9 這些），還有 MJ 出的圖片偶爾會帶出一些黑邊、假的小字和浮水印字，這些也順便讓 Claude 一起去掉。

這裡還有兩個細節，會直接影響後面的影片：

  • 參考圖上別帶像波浪一樣的紋路，模型會把它當成水，在生成的影片裡讓它流起來。
  • 如果同一個地方出了不同視角的好幾張場景圖，那就一定要核對每張圖裡門、窗、桌子的位置是不是一樣。如果對不上，就重新生成，或者只留一張。

然後等我體驗完 MJ 之後，我還發現一件挺有趣的事，就是我之前在小紅書上看到很多賣桌布的創作者，發一些特別好看、很有風格的圖片，然後在個人店鋪上架原圖，可以賣出幾百上千單，我之前也買過，然後我用 MJ 嘗試生成了一下，發現特別容易就生成出來了，哈哈哈哈哈哈好像發現了什麼了不得的商機。

二、影片：Seedance 提示詞（prompt）怎麼寫、參考圖怎麼給

1、一支影片裡如果有好幾個鏡頭，提示詞（prompt）就按鏡頭分段寫

我每一支影片的提示詞（prompt），大概的格式都是這個樣子的：

說明：可以生成音效。嚴格保持角色和道具的畫風與質感。
參考圖：小屋全景（不作為關鍵幀）@圖像1；男主角定妝照 @圖像2 @圖像3；男主角的手 @圖像4。
鏡頭01｜0—5秒　景別：……　運鏡：……　畫面內容：……　聲音設計：……
鏡頭02｜5—10秒　景別：……　運鏡：……　畫面內容：……　聲音設計：……

這麼寫有幾個原因：

  • 參考圖要一張一張對上，寫清楚每張是什麼（@圖像N）。不寫清楚的話，模型就分不清哪張是哪個鏡頭的，場景和人物就很容易串。
  • 場景全景後面加一句「不作為關鍵幀（keyframe）」，是告訴它這張只是參考場景，不要把它當成畫面直接拍出來；
  • 每個鏡頭只標起止的秒數，裡面寫成一段連著的話就行；
  • 像腳步聲、開門聲、台詞這些，單獨寫在每個鏡頭最後的「聲音設計」裡。

光看格式可能還是不太好想像，舉一個完整的例子，場景是我隨便編的，用的時候換成自己的人物和場景就行：

說明：可以生成音效。嚴格保持角色和道具的畫風與質感。

參考圖：便利商店門口全景（不作為關鍵幀）@圖像1；女主角定妝照 @圖像2 @圖像3；男主角定妝照 @圖像4。

鏡頭01｜0—5秒　景別：全景。運鏡：固定機位。畫面內容：夜裡下著小雨，便利商店的白光照在濕漉漉的地上。女主角撐著傘站在門口，在畫面左側，低頭看手機。隨後店門被推開，男主角提著塑膠袋走出來，停在畫面右側。聲音設計：雨聲，店門打開的提示音，塑膠袋的沙沙聲。

鏡頭02｜5—10秒　景別：過肩中近景。運鏡：鏡頭極慢地向前推近。畫面內容：攝影機在男主角身後、略高於肩膀，他的肩膀和後腦在畫面右側前景，虛化；女主角在畫面左側，抬起頭看向他，焦點在她的臉上。第 7 秒，她輕聲說：「你也沒帶傘？」聲音設計：雨聲，她的台詞，遠處有車開過。

2、參考圖模式和首幀模式，只能二選一

Seedance 有兩種模式，而且不能同時用：

  • 參考圖模式：帶上場景圖、定妝照，人臉最穩；
  • 首幀模式：直接指定第一幀，機位最穩，但是就帶不了定妝照。

所以接著上一支往下拍的時候，「機位一模一樣」和「人臉不變」，我們就只能選一個。

還有一個辦法是換成參考圖模式，把上一支影片的最後一幀當作第一張參考圖，再帶上定妝照，這樣人臉就不容易變，但是兩支影片接起來的地方又會跳一下。

所以我現在是這麼選的：

  • 只重拍一個鏡頭、機位要完全不變、畫面裡又沒有要認臉的人，那就用首幀模式；
  • 要人臉不變就用參考圖模式，然後在兩支影片接起來的地方換個機位，或者插一個別的鏡頭，把跳的那一下掩蓋起來。

3、參考圖比提示詞（prompt）的權重更高

這是我最近對 Seedance 最深的一個體會，當參考圖和文字描述不一樣的時候，影片模型都是以參考圖為準。比如截了上一支影片的一幀當參考圖，然後在提示詞（prompt）裡寫：換成高處俯拍機位，出來的影片還是照著截幀的機位拍的。

但是反過來說，參考圖用好了也是非常好使的，所以可以這麼分情況使用：

  • 需要換機位的鏡頭，就別給上一支影片的截幀，給定妝照，再用文字寫清楚他從哪邊進來；
  • 要拍人物後腦、側面，人物參考圖就給側面或背面的圖；
  • 不想在影片裡出現的東西，就必須從參考圖上去掉。

三、鏡頭：機位、運鏡、焦點提示詞（prompt）清單

鏡頭語言這個東西，很多人（包括我自己）其實都很難用專業的語言描述清楚，但是一部好看的片子，焦點和景深其實一直都在變化。

所以我把最常用的幾種機位、運鏡和焦點手法，整理成了一份清單。方括號裡的內容換成你自己的，就能直接用：

  • 淺景深（shallow depth of field）（適合：情緒鏡頭；對話裡的單人鏡頭；想讓觀眾只看一個人）
近景，固定機位。使用大光圈淺景深，焦點始終在[人物]的眼睛上，前景的[物件]和身後的[背景]柔和虛化。
  • 焦點跟隨（follow focus）（適合：關鍵道具被拿起、掉落、遞出去）
特寫，鏡頭跟著[物件]微微下移。焦點跟隨[從手裡滑落的鑰匙]，一路跟到[地面]，背景迅速虛化。
  • 前後拉焦（rack focus）（適合：注意力轉移；揭示；一個人發現了另一個人或一件東西）
[貼地低機位]，前後景拉焦。起初焦點落在前景的[A]上，後景的[B]是虛的。隨後[B 開口說話 / A 抬眼看過去]，焦點從[A]拉向[B]，[A]隨之虛化。使用大光圈淺景深，焦點轉移前後形成明確虛實變化。
  • 過肩（over-the-shoulder shot）（適合：兩人對話、審問、對峙）
過肩中近景。攝影機在[A]身後、略高於肩膀，[A]的肩膀和後腦在畫面左側前景，虛化；[B]在畫面右側，面朝鏡頭，焦點在[B]的臉上。
  • 反打（reverse shot）（適合：和「過肩」連著用。兩個鏡頭裡 A 始終在左、B 始終在右）
反打，過肩中近景。攝影機換到[B]身後，[B]的肩膀和後腦在畫面右側前景，虛化；[A]在畫面左側，面朝鏡頭，焦點在[A]的臉上。
  • 慢推（slow push-in）（適合：情緒在累積；人物在想事情；緊張來臨之前）
中景，鏡頭極慢地向前推近，從[腰部以上]推到[胸口以上]，整個鏡頭只推一點點。
  • 跟拍（tracking shot）（適合：人物走進一個新地方；追趕；帶觀眾進入場景）
跟拍，攝影機在[人物]身後約兩公尺、肩膀高度，跟著[人物]走進[巷子]，手持輕微晃動，[人物]始終在畫面中間。
  • 手持（handheld）（適合：衝突、慌亂、要紀實感）
手持拍攝，輕微晃動，像有人拿著攝影機站在旁邊。
  • 固定機位（static shot）（適合：冷靜、對峙；讓畫面裡的動作自己說話）
固定機位，鏡頭不動。
  • 貼地低機位（ground-level low-angle shot）（適合：人物登場；壓迫感；拍掉在地上的東西）
貼地低機位仰拍，攝影機放在[地面]上，[人物]從遠處走近，靴子在前景越來越大。
  • 俯拍主觀（high-angle POV shot）（適合：人物看清一件關鍵的東西：信、照片、證件）
俯拍主觀鏡頭，模擬[人物]低頭看的視線：兩隻手捧著[照片]，拇指慢慢抹開上面的[灰塵]。
  • 航拍（aerial shot）（適合：開場交代地點；結尾拉遠收束）
航拍，攝影機從高處緩慢向前飛，俯瞰[雪原上的小鎮]，[一輛車]沿著公路駛入畫面。
  • 上升（rising shot）（適合：一場戲的結尾：離開人物，留一點餘味）
鏡頭從[人物]身邊緩緩升高，越過[屋頂]，人越來越小，最後露出整個[街區]。

用這份清單的時候，有幾點一定要注意一下：

1、五種常用景別，提示詞（prompt）這樣寫

機位表裡經常出現「全景」「中景」「近景」這些詞，可能很多人分不太清，簡單來說其實就是人在畫面裡佔多大。我把最常用的五種整理了一下：

  • 遠景：人在畫面裡很小，主要拍環境。提示詞（prompt）：遠景，[人物]在畫面裡很小，[雪原、城市、海邊]佔滿整個畫面。這種就適合用在開場交代地點、結尾收尾，或者想拍出一個人很孤單的感覺。
  • 全景：人從頭到腳都在畫面裡，看得清他在什麼地方、在做什麼。提示詞（prompt）：全景，[人物]全身在畫面[左側]，[房間、街道]的樣子看得清清楚楚。適合人物進場、交代人和環境的關係。
  • 中景：拍到腰部以上，能看清動作，也能看到一點表情。提示詞（prompt）：中景，[人物]腰部以上，[正在做的事]。大部分對話和動作用它就夠了。
  • 近景：拍到胸口以上，表情看得很清楚。提示詞（prompt）：近景，[人物]胸口以上，焦點在眼睛上，背景虛化。適合說重要的台詞、情緒變化。
  • 特寫：只拍臉，或者只拍一隻手、一件東西。提示詞（prompt）：特寫，[手裡的鑰匙、桌上的信]佔滿畫面，背景完全虛化。適合關鍵道具和最重要的一個反應。

一場戲裡景別最好有遠有近，如果一直用同一種景別的話，看久了畫面會很悶。

2、拉焦（rack focus），一定要寫清楚這五件事

  • 提示詞（prompt）開頭就要寫：前後景拉焦
  • 說清楚焦點一開始在哪。
  • 焦點為什麼動，要有一個理由：有人說話、目光被吸引過去、人走開露出了東西。
  • 焦點落到哪，原來焦點在的地方怎麼變化？比如：隨之虛化。
  • 最後可以加一句：使用大光圈淺景深，焦點轉移前後形成明確虛實變化，會更加明顯。

3、一場兩個人的對話戲，機位可以這樣排

對話場景是最常見、也最容易拍得很平的戲。我實際測下來比較穩的一套排法，是用這五種鏡頭：

  • 定場全景（establishing shot）：先交代兩個人在哪，誰在左、誰在右；
  • 過肩（over-the-shoulder shot）：機位在 B 對面 A 的肩部往前一點的位置，拍 B 說話；
  • 反打（reverse shot）：拍 A 回話，過肩和反打可以來回切著用；
  • 單人近景（single close-up）：情緒最重的那一句，給說話的人一個近景；
  • 插入特寫（insert shot）：手裡的東西、桌上的道具，給觀眾喘口氣，也方便剪輯。

用過肩反打，一定要分清楚左右

比如現在有兩個人對話，A 在畫面左邊，B 在畫面右邊，那麼不管鏡頭怎麼切，A 都要一直在左，B 一直在右。

如果這個鏡頭有很多人，那就更要注意。開拍前最好先畫一張從上往下看的站位圖：誰在左、誰在右、出口在哪邊，然後每個機位的提示詞（prompt）裡都寫明「巷口在畫面左邊」這種話。

對話寫好以後，可以直接把下面這段發給 AI，讓它幫你拆成鏡頭：

下面是一場兩個人的對話戲：[把對話貼在這裡]。
人物：A 是[誰]，B 是[誰]；地點：[在哪]。
幫我把它拆成影片鏡頭，鏡頭從這幾種裡選：定場全景、過肩、反打、單人近景、插入特寫。
要求：
1. 第一個鏡頭用定場全景，交代兩個人的位置。
2. A 始終在畫面左邊，B 始終在畫面右邊，每個鏡頭的提示詞裡都寫明誰在左、誰在右。
3. 每個鏡頭寫清楚：景別、機位、運鏡、焦點在誰身上、誰說哪一句台詞、在第幾秒說。
4. 情緒最重的那一句，用單人近景。
5. 插入特寫只拍對話裡提到的東西。
6. 最後列一張表：鏡頭號、景別、誰在說話、台詞。

四、聲音決定一部片子的質感，但是也更容易被忽略

1、Seedance 可以生成配樂音效，那為什麼不讓一個模型把聲音全包了？

我一開始也想過：配樂、人聲、音效，能不能一個模型全做完？查了一圈，發現不行：

Seedance 每支影片都會自己配一段音樂，但是每支配的都不一樣，而一支完整的影片是很多段接在一起的，那這就有問題了，接在一起就會跳，而且出來的就是混好的一整條，沒辦法分開調整。

豆包的 Seed Audio 1.0 一條提示詞（prompt）就能出對白、配樂、環境聲，但是它不看畫面，音效對不上畫面。

所以最後我把聲音拆成了四塊，各用各的工具：

  • 人聲和對得上畫面的音效：Seedance 生成影片的時候一起出；
  • 影片裡自帶的音樂：用 BandIt Plus 拆分；
  • 配樂：Suno；
  • 環境聲：豆包音訊生成。

2、台詞一定要在生成影片的時候寫進去

台詞要對上口型，只能讓 Seedance 在生成影片的時候一起出，如果後期再配的話，口型就是對不上的。

提示詞（prompt）寫法就是寫清楚誰說、第幾秒、什麼語氣，比如：第 3 秒，她壓低聲音、帶著警告的語氣說：「別動。」

還有兩個細節：

  • 人物背對鏡頭、或者在畫面外，雖然看不見嘴巴，但是只要這個鏡頭有台詞，也照樣寫進去，讓模型拍出來。
  • 畫面外有人說話的時候，要寫清楚在畫面裡露臉的人物嘴巴不動、不開口，不然它會讓畫面裡的人去對口型。

3、聲音樣本：讓同一個人在每支影片裡都是一個聲音

同一個人在不同的影片片段裡說話聲音也會變，主要原因還是因為影片是分段拍的，所以每個要說話的人，第一次開口的那支拍好以後，我會用拆聲音的工具，把人聲拆出來，剪一句 2 秒以上、沒有音樂、沒有雜音的台詞人聲，當作他的聲音樣本。之後再拍到這個人，每支都帶上這段樣本。這樣操作之後，我讓 AI 量過，同一個人在兩支影片裡的音高幾乎一樣，幾乎是聽不出來差別的。

4、為什麼一定要拆音軌？

上一篇我也提過 Seedance 2.5 會偷偷混進音樂，那時候我的辦法是：這種影片自帶的聲音，直接不要，但是那是在沒有台詞人聲的情況下。

如果片子裡有台詞，那台詞聲音就和背景音樂、人聲這些混在同一條音軌裡面，所以就只能用影片自帶的那一軌。

所以如果不拆就會有三個大麻煩：

第一，每一支影片墊的音樂都不一樣。剪在一起以後，每切一個鏡頭，背景音樂就換一首，聽起來非常亂。

第二，它會和 Suno 做的正式配樂疊在一起，兩層音樂互相打架。

第三，台詞、音效、音樂全混在一個音軌裡，沒法單獨調。想把台詞調響一點，它的音樂也跟著變響；想把音樂壓下去，台詞也跟著變小，沒辦法單獨調節。

BandIt Plus 是做什麼的？

它是一個專門拆影視聲音的開源模型，可以把一段聲音拆成三層：人聲（對白）、音樂、音效。這樣拆完以後把音樂層丟掉，只留人聲和音效，再把 Suno 的配樂放上去，聲音一下就乾淨了，還可以單獨調響度。

BandIt Plus 怎麼安裝？

BandIt Plus 在 GitHub 上的一個開源專案裡（Music-Source-Separation-Training），自己裝會有點麻煩。不用自己研究，把下面這段話發給 Claude，它會幫你裝好、寫好批次拆分的腳本：

幫我在這台電腦上裝好 BandIt Plus，用來拆影片裡的聲音：
1. 用 GitHub 上的 ZFTurbo/Music-Source-Separation-Training 專案，單獨建一個 Python 環境，不要動我電腦上別的環境。
2. 下載 BandIt Plus 的模型，就是把聲音拆成人聲（speech）、音樂（music）、音效（effects）三層的那個。
3. 寫一個批次腳本：把 [影片資料夾] 裡每支影片的聲音拆成三層，按「原檔名_人聲」「原檔名_音樂」「原檔名_音效」存到 [輸出資料夾]。
4. 先拿一支影片試，拆好告訴我檔案放在哪，我聽過沒問題，再全部跑。

5、Suno：先定一段主旋律，再翻成不同的情緒

我覺得 Suno 是現在最強的音樂生成 AI，音樂品質最好。

選它還有一個原因：同一段主旋律，可以用 Cover 按不同的情緒翻成好幾版，這樣全片的配樂聽起來就是統一的，不會每一場都像換了一部片子。

不過這一點我是後來才想明白的。一開始幾首配樂是各寫各的，放在一起根本不像一部片子。後來才改成：先定一段主旋律（我用的是開場那首），再用 Cover 按每一場的情緒去翻。

幾個用 Suno 的小技巧：

  • 翻的時候，Audio Influence 調到 70% 左右，旋律就不容易跑，但情緒能變；
  • Styles 裡寫短標籤就行，不要寫長句子，它讀短標籤更準；
  • 如果在這首曲子裡有你不想要的風格，就直接寫進 Exclude styles 裡，相當於排除。

Styles 不會寫，就讓 AI 幫你寫

同一段主旋律，每一場的 Styles 不一樣，翻出來的情緒就不一樣，把下面這段發給你的 AI 就行：

幫我寫 Suno 的 Styles，用來 Cover 一段主旋律：
1. 這一場的情緒是 [緊張 / 回憶 / 釋然]，畫面是 [一句話說清楚這場戲]。
2. Styles 只寫 5 到 8 個英文短標籤，用逗號隔開，不要寫句子。
3. 再寫一行 Exclude styles，列出這一場不想要的風格。
4. 給我 3 組不同的寫法，我挑一組去試。

6、豆包音訊生成：音效提示詞（prompt）寫清楚四件事

豆包音訊生成（Seed-Audio 1.0）在火山方舟的體驗中心裡就能直接試，人聲、音效、環境聲、背景音樂它都能出，一次最長兩分鐘左右。我主要拿它做音效和環境聲，提示詞（prompt）寫清楚這四件事就行：

  • 什麼在響：門、腳步、對講機、風……
  • 在什麼地方：空房間裡、戶外、隔著一堵牆、從對講機裡傳出來；
  • 聲音是什麼質感：悶的、遠的、尖的、帶電流的；
  • 多長：一聲，還是持續 30 秒。

比如像下面幾個例子：

對講機：警用對講機裡傳出的男聲，聲音發悶、帶電流的沙沙聲，開頭有一聲短促的按鍵音，他說：「[台詞]」
環境聲：深夜空曠的街道，遠處偶爾有車開過，風吹過電線，沒有人說話，30 秒
單個音效：生鏽的木門被慢慢推開，吱呀一聲，在安靜的室內，2 秒

生成出來的音效單獨一條，後期想放在哪一秒、放多大聲，都可以自己定。

五、後期：不用會剪輯軟體，把要求說清楚就行

前面表裡寫了，剪輯、調色、混音、匯出成片都靠 ffmpeg 和 Python 這兩個小工具。用這兩個工具，你完全不用會寫程式，也不用記任何指令，把要做的事用大白話告訴 Claude，它會自己寫腳本、自己跑。

最難的其實是向 AI 把要求說清楚。說得太籠統，比如「幫我剪一下」「調好看一點」，它只能自己猜，猜錯了又得返工。

所以我把後期最常用的幾樣活，都整理成了提示詞（prompt）。方括號裡的內容換成你自己的，直接發給它就行。

1、剪輯：先讓它寫一張剪輯表

剪輯別一刀一刀口頭說，讓它先把每一段寫成一張表，你在表上改，比在對話裡來回說清楚得多。

幫我把 [影片資料夾] 裡的素材剪成一支粗剪：
1. 先寫一張剪輯表，每一行寫：順序、用哪支影片、從第幾秒到第幾秒、這一段講的是什麼。
2. 按 [分鏡表] 的順序排，每支影片去掉開頭和結尾沒用的部分。
3. 表寫好先給我看，我確認了再剪。
4. 切點要準到幀。除了我說的地方，不要改順序，不要調速度。
5. 剪好以後，在每個切點前後各截一張圖，檢查有沒有跳幀、黑幀，有問題列出來告訴我。

2、轉場（transition）：說清楚在哪、用什麼、多長

幫我加轉場：
1. [第 3 段] 結尾淡到黑，用 [1] 秒，聲音一起淡出。
2. [第 5 段] 和 [第 6 段] 之間用 [0.5] 秒疊化。
3. 片名出現之前，畫面先慢慢暗到黑，片名再慢慢出來，各用 [3] 秒。
4. 其他地方都是直接切，不要自己加轉場。

最後一條很重要。不寫的話，它有時候會覺得「加個轉場更好看」，到處給你加疊化轉場。

3、調色：給它一張參考圖，先出樣片

調色最難的是怎麼描述你想要的感覺。「高級一點」「電影感」這種詞，每個人理解都不一樣，最好直接給它一張參考圖。

幫我給整片調色：
1. 我想要的感覺是 [對比再強一點 / 整體再亮一點 / 顏色再淡一點]，參考這張圖：[參考圖]。
2. 先從 [第 30 秒] 開始出一段 [10] 秒的樣片。
3. 再挑三個不同的畫面，各做一張調色前、調色後左右並排的對比圖給我看。
4. 我確認了再調整片。

4、放大：低解析度放到高解析度

這些影片是 [720P] 生成的，幫我放大到 [1080P]：
1. 用清楚一點的縮放方法，再加一點點銳化，不要銳化過頭，如果邊緣出現白邊就是過頭了。
2. 先放大一段 [5] 秒，和原片並排做一張對比圖給我看。
3. 確認了再批次放大全部影片，放大後的檔案另存，不要覆蓋原片。

5、混音：人聲、音效、配樂分開放

前面聲音部分已經把人聲、音效、配樂拆成了幾軌，最後要把它們混回一條。

幫我把聲音混成一條：
1. 一共三軌：人聲在 [人聲資料夾]，音效在 [音效資料夾]，配樂是 [配樂檔案]。
2. 人聲最清楚，音效第二，配樂墊在最下面。
3. 整片的響度統一，適合發到 [平台]。
4. 先出 [某一段] 的小樣，告訴我每一軌分別調了多少。

6、字幕：中英雙語壓進畫面

幫我給成片加中英雙語字幕：
1. 台詞在 [台詞表] 裡。按畫面裡人物開口、閉口的時間對齊，先出一個字幕檔給我檢查時間。
2. 中文在上、英文在下，英文小一號。白字，加一圈細黑邊，放在畫面底部，離底邊留一點空。
3. 字型用 [蘋方 / 思源黑體]。
4. 先出一段 [20] 秒的樣片給我看。

時間對齊這一步我們一定要先檢查一遍，字幕早出來半秒、晚消失半秒，看著都會很彆扭。

7、匯出成片：最後一步也別偷懶

幫我匯出最終成片：
1. 畫面 [1920×1080]，[24] 幀，手機和網頁都能直接播放。
2. 畫質盡量高，但檔案別太大，發 [平台] 不會被壓得很糊。
3. 需要的話加浮水印 [@你的名字]，放在 [右上角]，不要擋住字幕和人臉。
4. 匯出以後，在開頭、中間、結尾各截一張圖給我看，再告訴我檔案大小和時長。

六、素材一多就亂：開工第一天先把資料夾建好

最後補一個最容易被忽略、但其實應該在開工第一天就做的事。表裡寫了，Claude Code 還負責「管檔案」。這件事聽起來很小，但做一部片子，圖、影片、聲音加起來幾百上千個檔案，最怕的就是檔案太雜太亂：找不到哪支影片用的是哪張參考圖，也分不清哪個是最新版。

所以我會先讓 Claude 把專案資料夾建好，之後所有東西都按這個規則放：

[片名]/
├── 01_劇情和分鏡/
├── 02_圖片/（場景、人物、道具分開放）
├── 03_影片/（每支影片一個資料夾）
├── 04_聲音/（聲音樣本、配樂、音效、拆出來的音軌）
├── 05_成片/
└── 06_腳本/

這裡面最好用的是「每支影片一個資料夾」：這一支的提示詞（prompt）、用到的參考圖、生成出來的影片，都放在一起。

建資料夾也可以直接交給它：

幫我建一個短片專案的資料夾，片名是 [片名]：
1. 按劇情分鏡、圖片、影片、聲音、成片、腳本分好資料夾，前面加上序號。
2. 圖片裡再分場景、人物、道具三個資料夾。
3. 影片按「場次_鏡頭號」一支一個資料夾，裡面放這一支的提示詞、參考圖和生成的影片。
4. 檔名用中文寫清楚是什麼，比如「酒吧_全景_1.png」，不要用一串數字。
5. 以後我給你的新檔案，你都按這個規則放好，放好告訴我放在哪了。

你可以帶走的重點

1. 每個環節交給最擅長的工具，再由 Claude Code 串起來

作者的分工：出圖用 Midjourney（MJ），生成影片用 Seedance 2.5，配樂用 Suno，音效用豆包音訊生成，拆音軌用 BandIt Plus，後期用 ffmpeg 加 Python。最後由 Claude Code 當「導演和路由」：串接各工具的介面、管檔案、寫腳本。作者特別提到，工具之間怎麼交接和配合，也是要解決的問題。

2. 先用風格代碼和情緒板定風格，再備齊三類參考圖

MJ 的風格代碼（--sref）和情緒板，讓幾十張、幾百張圖放在一起，風格也不容易跑偏。每個鏡頭要備三類圖：每個場景一張全景、每個露臉的人物一套定妝照（正臉、全身、手）、關鍵道具。定妝照和道具用純色背景，否則背景裡的雜物會被帶進影片；同一個人先出一張滿意的正臉，再當全身和手的參考圖。出完圖後，讓 Claude 或 Codex 統一畫幅，並去掉黑邊、假的小字和浮水印字。

3. 參考圖比文字重，兩種模式只能二選一

作者對 Seedance 最深的體會：參考圖和文字描述不一樣時，以參考圖為準。例如拿上一支影片的截幀當參考圖，提示詞（prompt）寫「換成高處俯拍」，出來的機位還是照截幀。另外參考圖模式（人臉最穩）和首幀模式（機位最穩）不能同時用，所以他的選法是：只重拍一個鏡頭、機位要完全不變、又沒有要認臉的人，用首幀模式；要人臉不變就用參考圖模式，並在兩支影片的接縫處換機位或插別的鏡頭。

4. 鏡頭語言可以用白話寫，先分清景別和左右

景別指的是人在畫面裡佔多大：遠景、全景、中景、近景、特寫，一場戲最好有遠有近。拍兩個人對話，作者實測比較穩的排法是五種鏡頭：定場全景、過肩、反打、單人近景、插入特寫。用過肩和反打時一定要分清楚左右：A 在左、B 在右，不論怎麼切都不能換。人多的鏡頭，開拍前先畫一張從上往下看的站位圖。

5. 聲音拆成四塊，影片自帶的音樂要拆掉

作者試過讓一個模型包辦聲音，但 Seedance 每支影片自帶的音樂都不一樣，接在一起會跳；豆包的 Seed Audio 1.0 不看畫面，音效對不上。所以他把聲音拆成四塊：人聲和對得上畫面的音效由 Seedance 一起出，影片自帶的音樂用 BandIt Plus 拆掉，配樂用 Suno，環境聲用豆包音訊生成。台詞要在生成影片時就寫進提示詞（prompt），口型才對得上。每個說話的人，還要剪一句 2 秒以上、沒有音樂和雜音的人聲當聲音樣本，之後每支影片都帶上。

6. 後期用白話說清楚，先看表或樣片，確認了再全部做

作者把後期最常用的幾樣活整理成提示詞（prompt）：剪輯、轉場、調色、放大、混音、字幕、匯出成片。共同的做法是先出剪輯表或樣片，你看過再批次處理全部。細節上，轉場最後要寫「其他地方都是直接切」，不然它有時會到處加疊化；調色最好直接給一張參考圖；放大後的檔案另存，不要覆蓋原片；字幕時間要先檢查，早出來半秒、晚消失半秒都會很彆扭。

怎麼開始

  1. 開工第一天，先讓 Claude 把專案資料夾建好：01_劇情和分鏡、02_圖片、03_影片、04_聲音、05_成片、06_腳本，其中影片「每支一個資料夾」，放這一支的提示詞（prompt）、參考圖和生成的影片。
  2. 在 MJ 用風格代碼（--sref）或情緒板定風格，照「場景全景、定妝照、關鍵道具」三類出參考圖，背景用純淺灰。
  3. 給 Seedance 的提示詞（prompt）照原文格式寫：說明、參考圖（寫清楚每張是什麼）、再按「鏡頭01、鏡頭02……」分段，每段標秒數、景別、運鏡、畫面內容、聲音設計。鏡頭手法從原文那份清單挑，換掉方括號裡的內容。
  4. 台詞寫進生成影片的提示詞（prompt）；影片生成後，把安裝 BandIt Plus 和批次拆分的提示詞（prompt）發給 Claude，丟掉音樂層，再配上 Suno 的配樂和豆包音訊生成的音效。
  5. 後期照原文的提示詞（prompt）範本依序做：剪輯表、轉場、調色、放大、混音、字幕、匯出成片，每一步都先看表或樣片，再批次處理。
