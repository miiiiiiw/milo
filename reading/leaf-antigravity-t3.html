一、Antigravity CLI：從安裝到用好

Antigravity CLI，就是 Antigravity 的命令列版本：在終端機裡跟 Gemini 4 對話，它直接讀寫你電腦上的檔案、跑命令。

官網：

https://antigravity.google

裝好以後，終端機裡敲的命令叫 agy，是 Antigravity 的縮寫。下文程式碼裡看到 agy，指的都是它。

不會用終端機也別怕。終端機就是一個打字的視窗，下面每一條命令都是複製、貼上、按 Enter。

1. 裝好：會員買哪檔、地區怎麼過、一行命令安裝

會員：直接買 Pro。

  • Plus 沒有 Neon；11 月 18 日起 Hydrogen 也只給 Pro 和 Ultra 了，Plus 在 Antigravity 裡只剩上一代的 3.8 Flash。
  • Pro 能用 Neon、Hydrogen、Argon、Orchestrator，還有 Claude Opus 5.5 和 Sonnet 5.5。
  • Ultra 多一個最強的 Carbon，額度是 Pro 的 5 倍或 20 倍。日常寫東西、看影片、出片，Pro 夠了。

黑色星期五 Pro 年繳 99.99 美元。我的買法：先開月繳，再去 Google One 會員管理裡點「更改會員方案」，切到「按年結算 US$99.99」。看清楚再點，月繳的錢會按天退回來，我退了 4 美元。

安裝：一行命令。

打開終端機（Mac 在「應用程式 → 工具程式 → 終端機」，Windows 用 PowerShell），貼上後按 Enter：

Mac／Linux：

命令（bash）

curl -fsSL https://antigravity.google/cli/install.sh | bash

Windows：

命令（bash）

irm https://antigravity.google/cli/install.ps1 | iex

這一步注意：別在命令前面加 sudo。加了會繞開你的代理，下載容易卡死。

裝完關掉終端機重開，輸入 agy --version，出現版本號就成了。我現在是 1.5.14。

登入：

進到你想讓它做事的資料夾，再輸入 agy：

命令（bash）

cd ~/Downloads/我的專案
agy

第一次會問配色、顯示方式，然後問「信不信任這個資料夾」，選信任。接著自動跳出瀏覽器，用訂了 Pro 的那個 Google 帳號登入，回到終端機就能用了。

在遠端伺服器上裝的話，它會印出一個網址：你在自己電腦上打開、登入，把頁面給的碼貼回終端機。

一鍵指令：裝好後發的第一句話

指令（text）

幫我做一次健檢：
1. 告訴我目前登入的會員檔位，能用哪些模型；
2. 執行 /usage，用中文解釋每個額度池還剩多少、什麼時候重置；
3. 檢查目前網路連 google.com 會不會被跳到 .hk，如果會，提醒我換節點。

怎麼確認裝好了：它能報出你的會員檔位和模型列表，就說明安裝、登入、地區三關都過了。

2. 上手：認介面、選模型、看額度，跑通第一個任務

認介面：記住這幾個鍵就夠了。

進去就是一個輸入框，打字按 Enter 就是派任務。

  • @：引用檔案或資料夾，比如 @腳本.md 幫我改第三段；
  • /：呼叫命令，第 5 節細講；
  • Shift + Tab：切換權限模式。預設是每條命令都先問你，往後依序是「自動接受修改」「自動」「只做計畫」。新手先用預設，看清楚它要做什麼再放行；
  • Ctrl + C：打斷它，閒置時連按兩下退出；
  • Shift + Enter：換行不送出；
  • Ctrl + O：展開工具輸出，想看它到底跑了什麼就按這個；
  • Ctrl + G：在你自己的編輯器裡寫長指令，寫完存檔就送出去。

選模型：Hydrogen 打底，Neon 攻堅。

輸入 /model 選模型，/effort 調思考強度。我的配方：

  • 日常、看影片、反推提示詞（prompt）：Hydrogen。 都說 Antigravity 慢，Hydrogen 實際用起來挺快；
  • 難的任務、要一次過：Neon，思考調到 XHigh；
  • 方案寫完要人挑毛病：Claude Opus 5.5。 它單獨一個額度池，平時都空著，後面講。

看額度：/usage 後面其實是三個池。

  • Gemini 池：Neon、Hydrogen、3.8 Flash、Orchestrator 都扣這裡，5 小時恢復一次，外面還套著一個每週上限；
  • Claude 和 GPT 池：Opus、Sonnet 單獨一池。池子很小，X 上有人用 Pro 實測，Opus 大約 160 萬令牌（token）就見底，只適合短而關鍵的任務；
  • Argon 池：Argon 自己一個每週額度。

三個池每週各自重置，不用就作廢。我寫這篇時看了一眼，Claude 池和 Argon 池還是 100%。

第一個任務：讓它看一條影片。

Gemini 4 最強的就是看影片，第一個任務就拿它練手。把一條影片放進目前的資料夾，直接說：

指令（text）

@clip.mp4 看一下這條影片，按鏡頭拆成分鏡表：每個鏡頭的時間、畫面、運鏡、字幕。最後反推一段能復刻它的影片提示詞，寫進 分鏡.md。

一條 10 秒的影片，Hydrogen 我實測 52 到 60 秒出結果，分鏡表、運鏡描述、提示詞都寫進檔案裡。

這一步注意：影片放在純英文路徑下，比如 ~/Downloads/agy_input/。中文路徑我遇過反覆斷線、沒有產出。

3. 配好：規則、Skill、MCP，讓它越用越懂你

能跑通第一個任務，基礎就夠用了。但用了幾天你會發現：每開一個新對話，都要重新交代一遍「用中文回答」「改檔案前先備份」；做熟的流程，每次都要從頭說。

這一節就是把這些「每次都要說的話」存起來。

規則：讓它記住你的習慣。

Antigravity CLI 每次開工，會先讀規則檔。全域規則放在下面任一位置，所有專案都生效：

路徑（text）

~/.gemini/GEMINI.md
~/.gemini/AGENTS.md

專案規則就在專案根目錄放一個 AGENTS.md 或 GEMINI.md。單一檔案最多 24KB。

我的做法：只維護一份正本。 我手上不止 Antigravity，還有 Claude Code、Codex、Grok。以前每家一份規則，改一條要改好幾遍，總有一家忘了改。現在我只改 Claude Code 的那一份，寫了個同步腳本，改完跑一下，Antigravity 的 GEMINI.md 自動重新產生。

想要一樣的效果，把這段丟給它：

指令（text）

幫我寫一個同步腳本：以我現在用的主力規則檔為唯一正本，產生 ~/.gemini/GEMINI.md。只有別家工具才有的工具名，換成通用說法；內容沒變就不重寫。

怎麼確認生效了：新開對話，問它「你的全域規則第一條是什麼」。我這邊它一開口就是「主公」。

Skill：把做熟的流程存成一條命令。

Skills（技能）就是一個資料夾，裡面一個 SKILL.md，寫清楚這件事怎麼做。放進去以後，它會變成一條斜線命令，你說到相關的事它也會自己呼叫。

全域的放這裡，專案層級的放 專案/.agents/skills/：

路徑（text）

~/.gemini/antigravity-cli/skills/

加完敲 /skills reload 生效。

我這邊放了 15 個，全是從 Claude Code 那邊用符號連結（symbolic link）連過來的，一份 Skill 兩邊用，改一處兩邊都生效。比如抖音影片下載的 Skill，丟一個連結它就自己下載、再接著拆解。

別人打包好的一組 Skill 叫外掛（plugin），一行裝好：

命令（bash）

agy plugin install https://github.com/<作者>/<儲存庫>

怎麼確認生效了：敲 /，看列表裡有沒有你剛放進去的 Skill 名字。

MCP：幫它接上外部工具。

MCP 是讓 AI 代理呼叫外部服務的插頭：瀏覽器、資料庫、Notion、影片產生……在對話裡敲 /mcp 就能管理，設定檔在這裡：

路徑（text）

~/.gemini/config/mcp_config.json

光說概念沒感覺。下一節就是我用一個 MCP＋一個 Skill，把會員裡的出片額度接進來的完整案例。

二、T3 Code：從安裝到用好

T3 Code 是一個開源的 AI 代理用戶端，GitHub 7 萬顆星，MIT 授權。它自己不帶模型，把你電腦上的 Claude Code、Codex、Antigravity、Cursor、Grok 都接進來，在一個介面裡用。

社群裡說用 Gemini 4 體驗最好的，就是它。

1. 為什麼它比 App 順手：一次實測講清楚 ACP

T3 接 Antigravity，走的是 Google 官方的 ACP 介面。ACP 可以理解成一個「標準插頭」：編輯器和 AI 代理按同一套規矩說話，任何編輯器都能接任何 AI 代理。

那它到底快在哪？我專門測了一次：同一條 10 秒影片、同一個 Hydrogen High，

  • 命令列 agy -p：60 秒（上午另一次 52 秒）；
  • 走 ACP（T3 的方式）：連上＋開工作階段 5 秒，做事 44 秒。

速度差不多，引擎還是那一台。 差別在過程：走 ACP，它會一邊想一邊把思考和工具呼叫推給你。那一輪它前後推了 11 段思考、2 次工具呼叫，第一段正式回答 35 秒才出來，但這 35 秒你一直看得見它在做什麼。

App 慢，慢在你什麼都看不見、只能乾等；T3 順，順在你一直知道它在做什麼。 再加上能回滾、一個介面開好幾個 AI 代理，用起來的感覺就完全不一樣了。

2. 裝好：安裝、接上 Antigravity、選模型和權限

安裝：

Mac：

命令（bash）

brew install --cask t3-code

Windows：

命令（bash）

winget install T3Tools.T3Code

不用命令列的話，直接去官網下載桌面版：

https://t3.codes/download

接上 Antigravity：

  1. 打開 T3 Code，左下角齒輪進設定，左邊欄 Agents 下面點 Providers；
  2. 找到 Antigravity，把右邊的開關打開；
  3. Runtime 那一行點 Install managed runtime，讓 T3 自己裝一份 Antigravity；
  4. Account 那一行點登入，在瀏覽器裡登入訂了 Pro 的 Google 帳號；
  5. 狀態變成 Authenticated · Google account，就接上了。

這一步注意：想用你自己裝的那份 Antigravity CLI，而不是 T3 託管的那份，就在設定裡的 Binary path 填它的路徑（Mac 一般是 ~/.local/bin/agy），版本要 1.5.12 以上。新手直接用託管的就行。

選模型和權限：

輸入框右下角選模型和思考檔位。列表直接來自你的會員方案，Pro 能看到 Neon、Hydrogen，也有 Claude 和 GPT。

輸入框裡：@ 引用檔案，$ 呼叫 Skill，/ 呼叫命令。

權限有四檔：

  • Supervised：每一步都問你；
  • Auto-accept edits：改檔案自動通過，其他操作還是會問；
  • Auto：一般操作自動通過，拿不準的問你；
  • Full access：全部放行。

這一步注意：新對話串預設是 Full access。 新手建議先去 Settings → Threads，把預設權限改成 Supervised，看熟了再放開。

每個對話串還能開自己的 git 工作樹（worktree）：AI 代理在一個獨立的副本裡折騰，你的主目錄保持乾淨，跑完看 diff 滿意了再合併，一鍵提交、推送、開 PR。

回滾：改壞了退回去。

每一輪都有檢查點，回滾會把檔案恢復到那一輪。

一個細節：Antigravity 自己不能倒帶對話，所以回滾以後，T3 會新開一個工作階段，把保留下來的對話重新餵給它。用起來沒感覺，長對話回滾後的第一輪會慢一點。

手機 App 遠端：躺在床上看它做事。

T3 有 iOS 和 Android 的手機 App。電腦這邊在終端機裡敲：

它會問你用 T3 Connect（不用折騰路由器）還是區域網路，選好後在背景常駐。手機打開 T3 App，登入同一個帳號，選這台電腦，就能看進度、發指令、批准權限。裝了 Tailscale 的，也可以走 Tailscale。

斷了怎麼接：發「繼續」。

跑長任務偶爾會斷，像上面 LogoBot 那次斷了 4 次。別慌，也別重開對話串：直接在原對話串裡發一句「繼續」，它會從斷掉的地方接著做，前面做的東西都在。

5. 邊界：這三件事還是回命令列

社群裡有人深度比較過 T3 和原生命令列，這幾點在 T3 裡吃虧：

  • /swarm 基本上不能用，子代理在 T3 裡只能看、不能管；
  • 大一點的 MCP 工具會被丟掉：Antigravity 的 ACP 介面會直接丟掉描述超過約 1280 位元組的 MCP 工具；
  • Skill 不能精確指定，只能靠模型自己猜要用哪個。

所以批量拆影片、自動出片這種重度用到 /swarm 和 MCP 的任務，還是回 Antigravity CLI。

一鍵指令：丟給 T3 裡的 Antigravity

指令（text）

先不要改任何檔案。
1. 讀一遍這個專案，告訴我它是做什麼的、進入點檔案在哪；
2. 列出你覺得最該先改的 3 個地方；
3. 等我選一個，再開一個 worktree 去改，改完給我看 diff。

三、兩個怎麼選，什麼任務用哪個

  • 看影片、拆爆款、反推提示詞：都行；批量用 CLI 的 /swarm
  • 一句話自動出片（接 Flow 點數和贈金）：CLI（要用 MCP＋Skill）
  • 讓 Claude Code／Codex 用上 Gemini 4 的眼睛：CLI 的 agy -p
  • 寫小工具、改專案，想看著它做：T3 Code
  • 改壞了一鍵退回：T3 Code（CLI 也有 /rewind）
  • 一個任務裡讓 Claude、Codex、Gemini 接力：T3 Code
  • 出門用手機盯：都行；想要手機 App 選 T3
  • 聊天、查資料、做調研：都不用，開 Gemini App 的「任務」

這篇在說什麼

Leaf Yeah!（@leaf_sanren）勸大家別在 Antigravity App 裡用 Gemini 4，改用兩個入口：Antigravity CLI（命令列）和開源用戶端 T3 Code。文章從會員檔位、地區排查、安裝登入講起，接著是 CLI 的介面、選模型、三個額度池、規則／Skill／MCP 設定、一句話出片，以及斜線工作流程和 agy -p；再講 T3 Code 怎麼透過 ACP 接上 Antigravity、做出一個 Logo 變機器人的小工具、多 AI 代理接力和回滾，最後列出兩者各自的邊界和分工。

每一節都附作者實測的數字（例如同一條 10 秒影片，命令列 60 秒、走 ACP 連線 5 秒加做事 44 秒；監視器風短片 42 個 Flow 點數），以及可以直接複製的命令和指令。

為什麼值得學

這篇最有用的觀念是：同一個模型，放在不同的工作環境（harness）裡，用起來可以差很多，而差別常常不在速度，而在你看不看得到它在做什麼、能不能退回、能不能並行。另外，作者把「怎麼排查地區問題」「哪種任務該用哪個斜線命令」「什麼時候該回命令列」寫得很具體，可以少走很多彎路。要注意的是：模型名稱、額度、價格和版本號都是作者撰文當時（2026 年 11 月）的實測；地區與帳號關聯國家的做法涉及 Google 的使用條款，要自己評估風險；T3 Code 對 Antigravity 的支援還在快速更新，動手前以各工具目前的說明為準。

你可以帶走的重點

1. 看得見過程，比快幾秒更重要

作者實測同一條 10 秒影片：命令列 60 秒，走 ACP（T3 的方式）是連線 5 秒加做事 44 秒，速度差不多，「引擎還是那一台」。真正的差別是 App 只顯示「思考中」，你只能乾等；T3 會一邊想一邊把思考和工具呼叫推給你，改壞了還能回滾。挑 AI 代理工具時，除了比模型，也要比它讓你看見多少、能不能中途接手。

2. 地區問題要一層層往裡查

登入報「not currently available in your location」，通常是地區沒過。作者的排查順序是：先換乾淨的節點；再處理 Google 帳號底層的「關聯國家」（只改 Google Play 沒用，要填表單）；最後確認節點沒有被 Google 的 IP 資料庫認成香港。裝好後用一段「健檢」指令，讓它報出會員檔位和模型列表，三關就一次確認完。

3. 把每次都要交代的話存起來

規則檔（GEMINI.md／AGENTS.md）記住你的習慣，Skill 把做熟的流程變成一條斜線命令，MCP 接上外部工具。作者手上有好幾個 AI 代理工具，所以只維護 Claude Code 那一份規則當正本，用同步腳本自動產生 GEMINI.md；Skill 則用符號連結（symbolic link）一份兩邊用。改一處、處處生效，才不會總有一家忘了改。

4. 依任務的形狀挑工作流程

作者用 Orchestrator 批量下載並反推 15 條影片、89 張圖，跑了一個半小時；後來才明白 Orchestrator 是「規劃、執行、回饋」一圈一圈串行，彼此不相干的批量任務應該用 /swarm 鋪開並行。同理：怕它亂改用 /plan，驗收標準明確用 /goal，難纏的 bug 用 /boost，/teamwork 很燒額度要慎用。

5. 兩個入口分工，而不是二選一

作者的組合是 T3 Code 當日常駕駛艙、Antigravity CLI 當背景工人：寫工具、改專案、要回滾、要多個 AI 代理接力時用 T3；批量 /swarm、接 MCP 自動出片、讓 Claude Code 透過 agy -p 借用 Gemini 4 看影片時用 CLI。因為 T3 走 ACP 有邊界（/swarm 幾乎不能用、大的 MCP 工具會被丟掉、Skill 不能精確指定），重度任務還是回命令列。

怎麼開始

  1. 確認會員方案能用你要的模型（作者建議 Pro），用一行命令裝好 Antigravity CLI，裝完用 agy --version 確認；不要加 sudo。
  2. 進到專案資料夾輸入 agy 登入，丟出作者的「健檢」指令；如果報地區錯誤，照節點 → 關聯國家 → IP 被認成香港的順序查。
  3. 放一條 10 秒影片到純英文路徑，用 Hydrogen 跑一次「拆分鏡表＋反推提示詞」，順便用 /usage 看三個額度池。
  4. 把最常交代的話寫進 ~/.gemini/GEMINI.md，把一個做熟的流程寫成 Skill，敲 /skills reload 後用 / 確認有出現。
  5. 想看著它做事時裝 T3 Code，在 Providers 接上 Antigravity，並先把新對話串的預設權限從 Full access 改成 Supervised。
