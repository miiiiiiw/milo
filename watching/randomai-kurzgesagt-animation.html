這支影片在說什麼

RandomAI 示範一條路線：不用自己會做動畫，只要在 Claude Code 裡選用 Claude Opus 5.5，再接上一個叫 HyperFrames Studio 的動畫框架（framework），就能做出 Kurzgesagt 那種扁平、色彩飽滿的 2D 解說動畫。他把流程拆成「畫面」和「聲音」兩半，每一半都用一段話交代給 AI 代理去做。

為什麼值得學

講者說，Kurzgesagt 每支影片從研究到動畫要花超過 1,200 小時的專業人力，而他的示範片只花了 40 分鐘01:25。就算成品還比不上真正的頻道，這個差距也說明了一件事：想做解說動畫的個人或小團隊，門檻明顯降低了。不過他也提醒，第一次的成果不會那麼精緻，要花時間和模型反覆修改。

你可以帶走的重點

1. 動畫分成兩半，各占一半

講者把整個流程切成「視覺動畫」和「音訊」，各約 50%。先把畫面做到滿意，再補聲音，每一半都能單獨檢查，出問題比較好找原因。03:13

2. 用一段話，讓 AI 代理自己把環境裝好

你不用碰終端機。在 Claude Code 開新工作階段、選 Opus 5.5，貼上一段提示詞（prompt）：說明想要的風格（扁平 2D 插畫、主角、流暢動態、旁白、配樂、音效），再請它安裝需要的東西、遇到要你動手的地方逐步說明，最後做一支十秒測試影片。04:16

3. 風格是「教」出來的：給它參考畫面

只給文字提示詞（prompt），動畫會動，但風格不夠高級。講者的做法是：把想要的風格那支影片截成多張圖上傳，再請模型研究配色、飽和度、發光效果、文字動畫，以及插畫怎麼在 2D 裡保有深度，然後用四秒的短片（兩隻螞蟻打鬥）測試。結果他形容為「品質大幅躍進」。06:16

4. 聲音：新手先上傳自己的旁白，音效交給 Python

講者的建議是，剛開始先手動上傳你自己的旁白檔，因為時間掌握會準得多。想更自動，可以讓模型透過模型上下文協定（MCP）連到聲音工具，連腳本和旁白一起產生。音效則可以請模型直接用 Python 合成，再疊到影片上。07:25

5. 調教完成後，可以幾乎全自動出片

講者的完整示範是一支四十秒、解說注射的影片：模型先寫腳本，他審閱後核准，之後旁白、畫面、音效都由模型接著做完。他說更長的影片（四到二十分鐘）也處理得了。重點是「腳本由人核准」這個檢查點，其餘交給系統。08:40

6. 先分清楚講者賣什麼

影片後半兩度推薦講者自己 Skool 社群裡的付費課程，裡面有現成的設定檔，下載後交給 Claude 就能用。付費路線是把講者調好的系統直接給你，省下自己反覆調整的時間；免費路線則是照影片自己建置。影片中沒有提到價格，要不要加入是你的決定。02:30

怎麼開始

  1. 先確認你能在 Claude Code 使用 Claude Opus 5.5。這個名稱與 Anthropic 官方文件一致。
  2. 照講者的示範，開新工作階段，貼上設定用的提示詞（prompt），請它安裝 HyperFrames 並做十秒測試。
  3. 找一支你喜歡風格的動畫，截多張不同場景的圖，上傳給模型，請它研究配色、飽和度、發光與文字動畫。
  4. 先要它做一支四秒的小動畫，滿意再做長的。
  5. 剛開始自己錄旁白或準備旁白稿，再請模型用 Python 加音效。
  6. 用「腳本先讓你核准」這個習慣，避免整支影片做完才發現方向錯了。
