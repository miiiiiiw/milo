開場：三種動效都能改、也能批次出 Three editable motion effects

00:00你現在看到的這些，這些，還有這些，非常有高級感的廣告動效：它的文字動畫、產品介面，還有這些發光的科技動效，都是用 Opus 5.5 來製作的。

00:11而且你不需要先學會 After Effects（AE），也不需要自己一行一行寫動畫程式碼，就能嘗試製作類似的影片。

00:19更有意思的是，做完之後還能修改文案、替換品牌，甚至批次產生不同的版本。

00:25所以今天，我們就從零開始，做出三種常見的高階動效，最後把它們整合成一條真正的宣傳影片。順便聊一聊，這種能力怎麼賺錢，以及有沒有人真的願意付費。全程無廣告，我們直接開始。

這和一般人工智慧剪輯有何不同 How this differs from AI editing

00:39那在開始之前，我們先要弄明白一件事情：用 Opus 做動態影片，和你平時用人工智慧（AI）剪輯工具，有什麼樣的區別呢？人工智慧（AI）剪輯通常需要你提供口播、螢幕錄影或其他素材，然後讓人工智慧（AI）把這些內容組織成一條影片。

00:53但我們今天做了這種影片，就算你沒有拍攝任何素材，也可以開始。

00:58例如我告訴 Opus：幫我做一個科技感產品介面，幾張功能卡片從螢幕中央依序展開，背景帶一點藍色光效。Opus 就會開始理解我的需求，並且按照我的要求編寫動畫程式碼，再呼叫 Remotion，讓 Remotion 按照這些程式碼，把文字、圖形和介面渲染（render）成影片。

01:19這意味著你得到的不只是一段固定的影片檔，還可以保留一套能夠繼續修改的動畫專案（project）。

什麼是動態圖形設計 What motion graphics means here

01:26今天我們做的內容，還有一個更專業的名字叫動態圖形設計（Motion Graphics），就是動態圖形設計，簡稱MG 動畫（motion graphics）。它特別適合動態文字、產品展示、資訊圖表、科技視覺這些場景。

01:39不過對於真人電影鏡頭、複雜的寫實場景，通常還是專門的影片生成模型（video generation model）更適合，類似 Seedance、可靈（Kling） 這樣的工具。好，關於影片製作的原理，我們知道這些就夠了。接下來開始動手實際操作。

準備工作：三樣工具 What you need to prepare

01:53這次我們主要會用到三個東西：Claude Code、Node.js，還有 Remotion。

01:59如果你是第一次接觸這些工具，那先去 Node.js 官網安裝長期支援（LTS）版本。安裝好之後打開終端機，輸入 node -v，結果能正常顯示版本號，就說明第一步完成了。

02:10然後開始安裝 Claude Code，按照頁面提示完成登入。使用 Opus 5.5 需要帳號或者應用程式介面（API）具有對應模型的存取權限。

02:19這裡還有一個大家比較關心的問題，就是使用 Opus 到底要花多少錢呢？如果你使用的是 Claude 的訂閱套餐，需要留意套餐的使用額度。像我們這種影片具體能做多少條，要看影片時長、動畫的複雜程度，以及你反覆修改了多少次。

02:35如果每次都重新開一個專案，從頭到尾跟人工智慧（AI）溝通，和你已經把製作流程固定下來、直接複用現有專案，消耗肯定是會不一樣的。所以這裡我建議大家記錄一次一次自己的真實製作成本，再判斷你適合哪種套餐。

安裝外掛、選模型、初始化專案 Plugin, model, and a first project

02:52接著是最關鍵的一步：Remotion 官方有一個專門給 Claude Code 使用的外掛（plugin），它能夠幫助人工智慧（AI）建立影片專案，同時提供製作 Remotion 動畫需要的技能規則（skills）。我們直接在終端機安裝，完成之後重新啟動 Claude Code，接著新建一個資料夾，專門存放這次的影片專案。

03:11進入資料夾以後，輸入 claude 啟動 Claude Code，然後輸入 /model，我們選擇 Opus 5.5。

03:18現在我們就可以讓人工智慧（AI）幫忙初始化一個影片專案，先不用做完整動畫，確認專案能夠正常執行就可以。接下來打開預覽介面，就可以一邊跟 Opus 對話，一邊查看它產生的畫面。

03:31如果你不習慣使用終端機，也可以打開Claude 桌面版（Claude Desktop），在 Code 的外掛（plugin）目錄裡面搜尋 Remotion，安裝官方外掛（plugin）。如果這裡遇到安裝失敗、找不到模型，或者打不開預覽，你也可以直接把完整報錯交給 Claude，讓它檢查目前專案和相依套件，確認能夠正常執行之後再繼續。

03:51這支影片提到的完整指令，我都會放在影片下方的連結當中，你可以直接複製就能用。

第二種動效：產品介面動畫 The product UI animation

03:57第二種效果。接下來我們把難度提高一點，製作第二類動效：使用者介面動畫（UI animation）。例如一款人工智慧（AI）軟體介面裡有任務列表、資料圖表、功能按鈕，你直接把截圖放進宣傳影片，通常沒有什麼吸引能力。

04:10但是如果鏡頭能夠在這些介面之間快速穿梭，任務卡片變成工作流程（workflow），工作流程（workflow）又變成資料圖表，它看起來就更像是一條經過設計的產品宣傳片。

04:21所以我們繼續給 NOVA AI 做一段 6 秒鐘的功能展示。這次的畫面我會展示 NOVA AI 的三個功能，分別代表：任務管理、自動執行和結果分析。不僅如此，這次我們還要讓它和剛才的片頭銜接起來，讓鏡頭從字母 O 裡面穿過去，直接進入產品工作臺。

04:41這裡就很適合 Remotion，因為文字、圖表、卡片這些元素，本來就能透過程式碼控制大小、位置和時間。產生之後，我們先觀察三件事情：卡片有沒有被遮擋，數字和文案能不能看得清楚，以及鏡頭的運動會不會太快。

04:57然後我們再做一個很重要的測試：我們不修改動畫結構，只把其中一張卡片的內容給替換掉。這樣如果以後我們的客戶想要修改產品賣點，或者做另外一個語言版本，我們就不用重新製作整段動畫了。同一套視覺結構可以衍生出不同的多個版本。當然前提是，你的程式碼設計足夠規範，而且不同長度的文字不會把版面撐壞。

05:21這裡我還要提醒一下：如果你準備拿去做真實的產品宣傳，最好使用客戶提供的真實產品資訊，不要為了畫面好看，而讓人工智慧（AI）給軟體產生它根本沒有的功能。

第三種動效：科技概念動畫 The tech-concept animation

05:32OK，接下來是第三種，就是大家很喜歡的科技概念動畫。例如你想表達一個人工智慧（AI）同時能夠調度很多工具，但直接講出來可能會比較抽象。那我們就可以讓螢幕中間出現一個人工智慧（AI）節點，把周圍的工具依序點亮，讓任務沿著光線被發送出去，完成之後再把結果傳回來。

05:51那這次我們再把節奏加快一點，讓上一段使用者介面（UI）裡的資料曲線直接變成節點網路（node network），鏡頭快速穿過不同節點，每經過一個節點就出現一個新的關鍵詞，最後多個節點一起點亮，鏡頭高速拉遠再迅速收攏成品牌標誌。

06:07這類畫面看起來很複雜，但其實不少效果是可以透過圓形、線條、文字和簡單的光效來實現的。

06:14這裡還有一個製作經驗小提醒：新手不要一上來就做特別複雜的 3D 場景，因為複雜的粒子、光照、鏡頭運動，都會增加人工智慧（AI）的除錯和渲染（render）成本，導致出片的時間被拉得很長。這樣反覆修改下來，新手是很容易被磨掉耐心的。所以我們先把核心動作做好，讓觀眾能看懂節點之間的關係，再逐步增加光效和空間感。

組裝、檢查與匯出 Assemble, inspect, and export

06:39好，現在我們把三段動態文字、產品介面和科技概念動畫連接起來，一條完整的三段式宣傳片結構就有了。現在我們有了三個鏡頭，還不能著急匯出。先看鏡頭之間有沒有黑屏閃爍，文字有沒有超出畫面，轉場是不是突然斷掉。有時候預覽看起來是沒有問題的，但是你暫停到某一幀的時候，就會發現它錯位了。

07:01如果希望它有更多發表會的感覺，還可以補充一些音樂和聲音設計。

07:06檢查完成以後，在 Remotion Studio 裡面點擊 Render，選擇 MP4 的格式，再確認輸出的位置。最終得到的就是一條可以播放、上傳和繼續剪輯的影片檔，而且專案程式碼都可以完整地保存。以後你想換文案、換品牌、調整鏡頭，都可以在這個專案裡面繼續修改。

學會以後怎麼賺錢 Four ways to monetize

07:25那接下來，就是大家最關心的問題：這個效果學會以後，到底能拿來做什麼、能不能賺到錢？

07:31先看我們剛剛做出來的這條影片，它只是一個演示作品。但如果裡面的品牌、功能介面換成真實產品，就可以進一步打磨成商業宣傳的素材。所以目前最直接的一條路，就是幫助應用程式（App）開發者、人工智慧（AI）產品團隊製作功能介紹影片。尤其是那些剛剛發布產品的小團隊，可能需要用影片讓使用者快速理解產品能做什麼。

07:54例如我們打開 Upwork，就能看到有人專門提供軟體即服務（SaaS）和應用程式（App）的產品演示影片製作。一個服務可能標價幾十到幾百美元。你可以從這些商品頁面上去研究，客戶需要什麼效果，以及對應不同的商務需求應該怎麼給商家報價。這裡的價格是公開的掛牌價格（list price），不代表賣家的實際收入。

08:15對於我們來說，如果想接類似的專案，就得先把作品做完整。你可以跟著我為大家整理的人工智慧（AI）剪輯課程，學習從 0 到 1 的完整成片流程。

08:27除了給產品團隊做宣傳影片之外，還有一類客戶，就是做內容創作，像科技、財經、商業頻道。他們可能經常需要資料增長動畫、關鍵詞強調、複雜流程解釋等。如果你能把這些做成模板，提供給這些創作者，那麼他們就不必每條影片都從頭創作，只需要套用你的模板就可以了。

08:44再往下就是電商廣告。一款產品可以用同樣一套動畫，替換不同的賣點、價格和語言，形成多條廣告素材。客戶真正需要的，可能是快速測試不同產品的表達方式。如果每次都要重新設計，成本那肯定會高很多。但如果動畫可以複用，很多重複的製作工作就有機會被自動化。

09:05那第四種就是出售模板。前面這些文字動畫、使用者介面（UI）展示和科技效果，都有機會整理成可以被反覆使用的素材或模板。那在 VideoHive 上面有一套叫 Videolancer's Transitions 的轉場模板，公開售價 59 美元，你看這裡累計銷量（cumulative sales）已經超過 4.1 萬次。不過需要說明，這是一套傳統的 After Effects（AE） 模板，而且銷量是長期累積的，不能直接當成作者收入。但至少說明使用者確實願意為能夠反覆使用的動效素材來付費。

09:36如果你想從接單這條路開始，但又不知道去哪裡找客戶，你還可以看看 Product Hunt。這個平台上有很多剛剛發布的軟體產品，你可以先看看他們的官網，有些只有靜態截圖，還沒有完整的宣傳影片。那如果你發現某個產品的一個功能很有意思，也可以嘗試製作一小段概念演示，再透過對方公開的商務聯絡方式，詢問有沒有這方面的一些製作需求。

10:00所以總結起來：用 Upwork 研究人工智慧（AI）影片動效服務怎麼賣，用 VideoHive 研究模板怎麼賣，用 Product Hunt 尋找可能需要宣傳片的產品和團隊。

客戶真正在意什麼 What clients actually pay for

10:12但這裡我發現一個很容易被忽略的問題：很多人工智慧（AI）動效看起來非常高級，當你發到社交平台上之後，也有很多互動和按讚，就是沒有客戶願意為它買單。為什麼呢？

10:23例如一家做記帳軟體的公司，想告訴使用者自己新增的自動分類功能，你給它做了一個漫天飛舞的粒子片頭，可能很漂亮，但是使用者看完還是不知道這個軟體能解決什麼問題。如果你用一段 15 秒的影片，讓使用者看見帳單自動整理好的全過程，那麼這條影片才開始具有明確的商業價值。

10:44客戶最關心的還是畫面能不能準確展示產品、品牌是否一致、修改是否方便、能不能按時交付等等。

10:52人工智慧（AI）可以幫你快速完成製作，但這些交付問題不會自動消失。還有一個更現實的地方：如果做一條影片，產生只花了十幾分鐘，返工卻花了兩天時間，那所謂的低成本就不再成立了。

11:05所以如果是我重新開始嘗試，我不會一上來就做一個影片產生平台。我會先找一款需要宣傳影片的產品，做一條 15 秒鐘的功能展示動畫，並且把花了多少時間、模型費用、修改了多少次，全部記錄下來。然後拿著作品去接觸真正有可能購買的人，看他們願不願意為這個品質而付錢。

收束 Closing

11:26OK，今天我們用 Opus 結合 Remotion，走完了一條動態影片從設計、產生、修改再到匯出的全流程。人工智慧（AI）已經開始降低動態影片的製作門檻，但它能不能降低普通人賺錢的門檻呢？還得靠一筆一筆的真實訂單來證明。

11:43如果你不想錯過下一期，記得訂閱我的頻道、打開小鈴鐺。我是子墨，專注各行業人工智慧（AI）落地。我們下期再見，掰掰。

這期要說明的不是「用人工智慧（AI）隨便生成一段影片」，而是用 Opus 5.5 寫出可改的動畫程式碼，再交給 Remotion 渲染（render）。你留下的是一套能改文案、換品牌、批次出不同版本的動畫專案（project），而不是一個不能拆的成片檔。

先分清兩條路，再決定要不要上手

人工智慧（AI）剪輯通常要你先準備口播、螢幕錄影或其他素材，再讓工具把它們編成一條影片。這條路上的 Opus 加上 Remotion 不一樣：就算還沒拍任何素材，也可以先口述需求，讓模型寫動畫程式碼，再由 Remotion 把文字、圖形和介面渲染（render）出來。它比較接近動態圖形設計（Motion Graphics），也就是MG 動畫（motion graphics），適合動態文字、產品展示、資訊圖表和科技視覺；真人電影鏡頭或複雜寫實場景，講者認為還是交給 Seedance、可靈（Kling） 這類影片生成模型（video generation model）更合適。

三種動效，組起來再檢查、再匯出

講者示範的流程是：用 Claude Code、Node.js 和 Remotion 搭好環境，安裝 Remotion 官方給 Claude Code 的外掛（plugin），輸入 /model 選 Opus 5.5，先初始化專案、打開預覽，確認能跑再繼續。不習慣終端機時，也可以在Claude 桌面版（Claude Desktop）的外掛（plugin）目錄搜 Remotion。本片沒有逐步拆解「第一種」動態文字片頭的製作過程，進入實作時是從第二類使用者介面動畫（UI animation）接上剛才的片頭：任務卡片變成工作流程（workflow），再變成資料圖表，再做科技概念動畫，最後把三段接成一條宣傳片。

實作時記得先記成本，也別替產品發明功能

使用 Opus 5.5 需要帳號或應用程式介面（API）對該模型的存取權限。費用會隨影片時長、動畫複雜度和返工次數而變；每次重開專案跟人工智慧（AI）從頭溝通，和複用已固定的流程，消耗也不一樣。講者建議把每一次真實製作成本記下來，再判斷適合哪種套餐。若要做真實產品宣傳，必須用客戶提供的真實產品資訊，不要為了畫面好看，讓模型幫軟體「生成」它沒有的功能。科技概念動畫也建議先把節點關係做清楚，再用圓形、線條、文字和簡單光效堆細節，不要一上來就上複雜的 3D、粒子和光照，以免渲染（render）與除錯把出片時間拉得很長。

四條變現路，三個平台各看一件事

學會動效之後，講者把變現拆成四條：幫應用程式（App）開發者和人工智慧（AI）產品團隊做功能介紹影片；把資料增長、關鍵詞強調、流程解釋做成可套用模板，提供給科技、財經、商業創作者；用同一套動畫替換賣點、價格和語言，產出電商廣告測試素材；以及把文字動畫、使用者介面（UI）展示和科技效果整理成可出售的模板。對應的觀察方式是：用 Upwork 看人工智慧（AI）影片動效服務怎麼賣，用 VideoHive 看模板怎麼賣，用 Product Hunt 找可能需要宣傳片的新產品和團隊。

客戶買單的是功能被看懂，不是粒子很華麗

很多人工智慧（AI）動效在社交平台上很能得到互動和按讚，卻沒有客戶願意付錢。講者舉記帳軟體為例：漫天飛舞的粒子片頭可能很好看，使用者看完還是不知道軟體能解決什麼問題；一段 15 秒讓人看見帳單被自動整理好的影片，才開始具有明確的商業價值。客戶真正關心的是：畫面能不能準確展示產品、品牌是否一致、修改是否方便、能不能按時交付。人工智慧（AI）可以加快製作，這些交付問題卻不會自動消失；若產生只要十幾分鐘、返工卻要兩天，「低成本」就不成立了。

可以帶走的做法

  1. 先分清自己要的是人工智慧（AI）剪輯（需要素材、編成片），還是 Opus 5.5 加 Remotion 這條動態圖形設計（Motion Graphics）路線（留下可改的動畫專案（project））。寫實鏡頭可交給 Seedance、可靈（Kling） 這類影片生成模型（video generation model）。
  2. 環境上先裝 Node.js 的長期支援（LTS）版本（用 node -v 確認），再裝 Claude Code，並確保帳號或應用程式介面（API）能使用 Opus 5.5。接著安裝 Remotion 官方外掛（plugin），用 /model 選好模型，先初始化、先預覽，確認能跑再繼續。
  3. 三種動效可以組成分段宣傳片：動態文字片頭、使用者介面動畫（UI animation）、科技概念動畫。組裝後先查黑屏、文字超出、轉場斷掉和單幀錯位，再在 Remotion Studio 匯出 MP4，把專案程式碼一併留下來。
  4. 做真實宣傳時只用客戶的真實產品資訊；改一張卡片文案，是在測試以後能不能換賣點、換語言。科技概念動畫先把關係做清楚，避免一上來就上重 3D 與複雜粒子。
  5. 變現可從功能介紹、創作者模板、電商廣告變體和出售模板四條路看起，並分別用 Upwork、VideoHive、Product Hunt 做功課。公開的掛牌價格（list price）和累計銷量（cumulative sales）都不等於實際收入。
  6. 先做一條 15 秒、能讓人看懂功能的展示，記錄時間、模型費用和修改次數，拿去問真正可能購買的人；不要把「產生很快」當成「交付成本很低」，也不要一上來就做影片產生平台。
