生圖要不要外接 API

每月 20 篇文章、160 張圖。升級訂閱、另訂一個方案，還是按張付費？把每條路攤開來算過一次，留給之後回頭對照的自己。

決策紀錄 · 2026-11-17 · 11-20 補上 $20 產量試算 · 11-22 補上 Google AI Pro 的月費評估與每月 $10 API 額度 · 價格皆為查詢當日的美元牌價

為什麼要算這一題

Grok Bot 產出的文章開始需要配圖：每篇一張封面、一張資訊圖表、六張圖文。手上是 Grok Premium 訂閱，生圖扣的是每週用量池，夠不夠用沒有把握。於是冒出兩個念頭：升級到每月 100 美元的 Super，或者外接一個便宜的生圖 API。另外也想知道，同樣 20 美元級的 Google AI Pro 搭 Antigravity CLI，和 ChatGPT Plus 搭 Codex CLI 比起來誰有優勢。

哪一條划算？憑感覺答不出來。訂閱看的是額度，API 看的是單價，兩邊單位不同，放不到同一張桌上。只好先定一個固定的工作量，再把每條路換算成「這個月要多付多少」。

算完之後的決定

假設動一下，結論還站得住嗎

當時的假設是每月 20 篇、三成重生、資訊圖表每張改 1.5 次、每次都附角色參考圖。這些數字日後一定會變，所以留成可以拉動的版本。篇數翻倍、重生率拉高，看排序會不會翻盤。

讀這張圖要記得的事

最便宜的三個模型和 GPT Image 2.6 套的是同一個重生率，這對它們是高估。Grok 舊版、MiniMax H3、GPT Image 2 的低畫質都沒有中文字的佐證，錯字一多，重生次數會往上走，有些錯字重生幾次也修不好。表面省下的 2 到 4 美元，很可能在校對時間裡賠回去。

Google AI Pro 和 Plus 一樣是固定月費，所以畫成那條虛線，不在長條裡。混搭也不划算：把「改用 Antigravity 的比例」拉到 100%，API 只剩約 $2.4，但加上 $19.99 月費合計約 $22.4，比全走 API 的 $9.1 貴一倍多。訂閱要划算，得是 API 帳單本身就超過 20 美元的時候。不過 Google AI Pro 附的每月 10 美元 API 額度，可以抵上面兩列 Nano Banana 的費用：全用 2.1 的 8.0 美元可全額抵掉，2.1＋Pro 的 13.1 美元只需自付約 3.1 美元。

GPT Image 2 和 2.6 只差一美元多。2.6 的低畫質用了約四倍的運算量，接近舊版的中高畫質，速度也快，這個差價付得心安。

Google AI Pro 的 $20 呢

Gemini CLI 已在 2026 年 6 月停止服務個人帳號，接手的是 Antigravity CLI。它用帳號登入，生圖扣的是訂閱額度，不必另付 API 費用，定位和 Plus 搭 Codex CLI 很像：固定月費、Bot 可以呼叫、張數不透明。差別是它的生圖額度和寫程式分開計算，這點比 Codex 有利；但有回報指出 CLI 的生圖子代理會忽略參考圖，對靠角色設定表維持人物一致的做法是致命傷。

它還附每月 10 美元的 Google Cloud 額度，可以抵 Gemini API 的費用。試算區那兩種 Nano Banana 配置算的就是走 API 的情況，訂了 Google AI Pro 時可以用這份額度抵掉，怎麼領取見下一節。

分界線在哪

  • 每月少於 44 篇（約 350 張）：API 比較便宜。照現在的 20 篇，一年約省 130 美元。
  • 每月超過 44 篇：Plus 開始划算，前提是 Codex 的額度撐得住。有人回報 Plus 一次跑約 20 張就吃緊，這個前提並不穩。
  • 用量起伏大的月份：API 的優勢更明顯，少用就少付；Plus 用多用少都是 20 美元。
  • Google AI Pro 多附每月 10 美元 API 額度：本來就要訂的話，等於每月約 300 張 Nano Banana 2.1 不用另付；只為生圖而訂，19.99 美元仍比 API 的 9.1 美元貴。

以現在的量，API 只花 Plus 的一半左右。要等文章量翻倍以上，才需要回頭重算這一題。上方試算區拉動篇數時，底下那行說明也會跟著算出 $20 能換到的張數。

附贈額度改變了這一題。Google AI Pro 每月附 10 美元的 Google Cloud 額度，可以拿去付 Gemini API；Bot 直接用 API 呼叫 Nano Banana，參考圖照常能附，正好繞過 Antigravity CLI 忽略參考圖的問題。10 美元約等於 300 張 Nano Banana 2.1。

所以兩個 20 美元級訂閱之間，Google AI Pro 占優：同樣的月費，多了 Antigravity 的獨立生圖額度和 10 美元 API 額度。和直接付 API 比，結論不變：只為生圖而訂，19.99 美元仍比 GPT Image 2.6 的 9.1 美元貴一倍；只有本來就要訂 Google AI Pro，這份額度才是白賺。

怎麼用每月 $10 額度

  1. 登入 Google AI Studio，左側會提示有未領取的額度，按「Redeem and Continue」領取；沒有 Google Developer Program 帳號的話會自動建立。
  2. 在同一個流程建立 Google Cloud 帳單帳戶，並預付至少 5 美元，之後才能開始扣額度。
  3. 領取時會附一把付費層 API 金鑰。Bot 用它直接呼叫 Gemini API 的 Nano Banana 2.1 或 Pro，參考圖照常附上。
  4. 到 aistudio.google.com/billing 看餘額。額度從最早到期的先扣，每筆有效 12 個月，可以逐月累積。

額度只有主要訂閱人能用，不能分給家庭成員。官方說可用於 Gemini API 與生成式媒體，但沒有點名圖片模型，第一次使用時先確認有扣到額度。

四張都是簡體字。文章是繁體的話，提示詞要寫明繁體中文並逐字給出，否則模型多半照樣輸出簡體。繁體筆畫更密，第四張那種小字的錯誤率只會更高。

低畫質可以用到哪裡

原本擔心 low 不堪用。查到的實測剛好相反：GPT Image 2.6 的 low 在部落格尺寸下已經像完成品，海報上的三段英文也全數拼對。邊界出現在小字，以及需要放大看的場合。

low 夠用

  • 一到三行、字級大的標題或標語
  • 顯示寬度 800 像素左右的首圖
  • 無字配圖、草稿、需要快速重生
  • 線性流程，4 到 6 個節點，每格 2 到 6 個字

升到 medium 或 high

  • 區塊多、有小標籤或註解的資訊圖表
  • 會被放大檢視或要印刷
  • 同一張圖要連續修改多次
  • 流程有分支、迴圈或超過 6 個節點

哪個畫質都要校對

  • 很小的字，字形會變軟或錯一個字元
  • 繁體中文小字，目前沒有實測數據
  • 數字必須完全正確的圖表，改用疊字

還有一個容易踩到的設定：quality 留成 auto 時，模型每次都選 low。資訊圖表若沒有自己寫明，就會悄悄用低畫質出圖。

  • 中文字的實際表現。查到的文字測試幾乎都是英文，「佐證最多」指的是英文測試與廠商定位，繁體的錯字率要自己測。
  • 局部修改與參考圖輸入的單次費用是估計值，參考圖那一項實際可能只有一半。
  • 三成重生率是假設。提示詞寫得好會更低，繁體錯字多會更高。
  • Premium 用量池裡一張圖扣多少，官方沒有公布，只能看帳號裡的 Usage 頁面。
  • Codex CLI 內建生圖用的是不是 2.6，沒有查到確認。
  • Nano Banana 2.1 的繁體中文表現沒有實測；它的參考圖輸入費（每次約 $0.001）是估計值。
  • Antigravity CLI 的生圖額度一週能撐幾張、用的是 Nano Banana 2 還是 Pro，都沒有官方數字。
  • Antigravity CLI 會忽略參考圖的問題還在 GitHub 上開著，沒有修正時程。
  • 從 Bot 在背景啟動 agy 是否合規，目前只有一則非官方的論壇回覆。
  • 每月 10 美元額度能不能付 Nano Banana 生圖：官方寫可用於 Gemini API 與生成式媒體，但沒有點名圖片模型。
  • GPT Image 2.6 上架才兩週，MiniMax H3 才一週，第三方數據都還薄。

如果又翻到這一頁

大概是用量變了，或者價格變了。先對照下面幾個門檻，哪一條被跨過，就重算那一條。

  • 每月成品超過約 350 張（約 44 篇），或生成次數接近 500 次：ChatGPT Plus 搭 Codex CLI 開始追平 API，值得重新比較。
  • Premium 的用量常在週中見底，而且吃掉額度的是聊天和 Bot：這時升級才有道理，生圖只是順便受惠。
  • 繁體錯字率居高不下：改成模型只出底圖與角色，文字事後疊上。
  • Antigravity CLI 的參考圖問題修好、實測一週撐得住約 58 張，而且 API 帳單已接近 20 美元：這時 Google AI Pro 才值得訂，回來重算。
  • 出現新模型或調價：回到試算區，把單價換掉再看排序。
